== Resource metadata

[IMPORTANT] 
====
Resource metadata information should be saved to the DwC-A dataset metadata file (eml.xml).
====

*Resource metadata* provides project- and/or dataset-level information for potential data users to understand the context of a dataset. GBIF's metadata schema is based on https://eml.ecoinformatics.org/[Ecological Metadata Language^] (EML), a metadata standard administered and maintained by https://knb.ecoinformatics.org/[The Knowledge Network for Biocomplexity^], which captures information about an ecological dataset in a series of modular and extensible XML documents. Each Darwin Core Archive must include a resource metadata file written in XML format: `eml.xml`. If you publish through the https://www.gbif.org/ipt[GBIF Integrated Publishing Toolkit (IPT)^], this file is created for you from the information you enter in the IPT metadata forms.

GBIF currently requires 8 dataset-level metadata terms (see https://www.gbif.org/data-quality-requirements-sampling-events[Data Quality Requirements for Sampling Events^] for more information):

* *_title:_* This is the title under which the dataset will be published at https://www.gbif.org/[gbif.org]. The title should be brief, but long enough and descriptive enough to characterize the dataset in an international context and distinguish it from similar datasets from other institutions. +
* *_description:_* A brief, textual description of the dataset. This may include an extended version of the title, a description of the geographic, temporal and taxonomic scope(s) of the dataset, information about the methodology implemented and purpose of the underlying data compilation (e.g. protected habitat surveillance, faunistic inventory, deep sea trawl data, survey steps or gear used), relevant literature references, and any other information you consider relevant to characterize the dataset. This is, in essence, a resource abstract. +
* *_publishing organization:_* The name of the institution or organization that will be listed as the data publisher at https://www.gbif.org/[gbif.org]. The publishing organization is the institution which holds or owns the dataset and is in charge of its contents and maintenance. +
* *_type:_* Type refers to the dataset structure reflecting the level of detail captured in the dataset. In GBIF, four types of datasets are currently accepted: sampling event, occurrence, checklist, and metadata. Type for survey and monitoring datasets is `samplingEvent`. +
* *_license:_* A machine-readable statement of the rights and intended use attached to the published dataset. GBIF supports the following Creative Commons
categories: CC0, CC BY, and CC BY-NC (see https://www.gbif.org/terms[GBIF Terms of use^]). +
* *_contact(s):_* The contact field contains contact information for a dataset. This is the person or institution to reach out to with questions about the use or interpretation of a dataset. The information for at least one contact is required to ensure the possibility of communication about the dataset. The minimum required information for each contact is name and email address. +
* *_creator(s):_* A resource creator is the person(s) or organization(s) responsible for creating a resource. Contact information for at least one dataset creator is required. The minimum required information for each dataset creator is name and email address. +
* *_metadata provider(s):_* The metadata provider is the person or organization responsible for providing documentation for a resource. At least one metadata provider must be listed. The minimum required information for each metadata provider is name and email address. 

These 8 terms must be populated in order to successfully publish a dataset to GBIF. See the https://ipt.gbif.org/manual/en/ipt/latest/gbif-metadata-profile[GBIF Metadata Profile – How-to Guide^] for comprehensive guidelines and a list of all available resource metadata terms <<GBIF2011>>.

[discrete]
==== NEON example: Resource metadata

The resource metadata for the published NEON tick-pathogen example dataset include the following required elements (as registered with GBIF):

[width="100%",cols="30%,70%",options="header",]
|===
|Metadata element |Example dataset value
|title |+NEON ticks sampled using drag cloths and tick pathogen status+
|description |A description of NEON's tick and tick-borne pathogen sampling (sampling methods, life stages collected, pathogens tested, and the hierarchical Event structure used with the Humboldt extension)
|publishing organization |+National Ecological Observatory Network+
|type |+samplingEvent+
|license |+CC BY 4.0+
|===

The dataset was also assigned a DOI on publication (https://doi.org/10.15468/b52b9z[10.15468/b52b9z^]). Contact, creator, and metadata provider details can be viewed on the https://www.gbif.org/dataset/12315bb8-8ab3-446a-b5a4-2be93aade242[dataset page^].
