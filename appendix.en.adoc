== Term quick reference

This appendix lists every term that appears in the term tables of this guide, grouped by the table in which it is prepared. For each term it gives the usage recommendation (see link:#using-this-guide[Using this guide]) and the section that explains how to use it. Terms that appear only in examples (for example, extended measurement or fact and Relevé extension terms) are not listed; see the relevant sections and the https://eco.tdwg.org/terms/[Humboldt Extension Quick Reference Guide^] for the full term lists.
